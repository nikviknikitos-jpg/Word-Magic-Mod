# WordMagicMod (Fabric 1.20.1)

Магия Древних Слов: 10 Томов Архимага.

## Управление
- R (К) — круговое колесо заклинаний.
- ПКМ Посохом Слова — произнести выбранное Слово.
- ПКМ Кинжалом Печати по Камню Древней Печати — пробудить Босса.

## Команды
- `/wordmagic_give` — посох, кинжал, камень печати, все 10 томов, свитки, катализаторы.

## Сборка
JDK 17, Gradle 8.8, GitHub Actions workflow прилагается.
